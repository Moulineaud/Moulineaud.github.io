Équations produit nul

Entraîne-toi à résoudre des équations de la forme (expression) × (expression) = 0.

Rappel : si un produit est nul, alors au moins l’un de ses facteurs est nul. Exemple :
(x − 2) × (x + 3) = 0
Donc x − 2 = 0 ou x + 3 = 0.
Les solutions sont x = 2 ou x = −3.

Réussite : 0 / 0

Sépare les solutions par une virgule. Écris « aucune » s’il n’y a pas de solution.
